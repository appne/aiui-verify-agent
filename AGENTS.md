Verification agent for the Rokid Glasses x iPhone project.

Purpose: on-device checks for (A) Bluetooth-forwarded networking from AIUI
(navigator.connection.type + an HTTPS fetch while glasses Wi-Fi is OFF).
Voice launch name should stay short (2-4 mora), e.g. "kensho".
This agent is for personal verification only; do not submit it for store review.
